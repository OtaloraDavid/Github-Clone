# Actividad 2 - Hands on: Configuración de Herramientas

Este repositorio contiene el desarrollo de la Actividad 2 del curso de Ciencia de Datos de UNIAGRARIA, enfocada en el uso de herramientas colaborativas y comandos básicos de Git.

## Proceso Seguido
Para el desarrollo de esta actividad, se realizaron los siguientes pasos:
1. **Creación del repositorio:** Se creó un repositorio en GitHub de manera individual.
2. **Clonación:** Se descargó el repositorio a la máquina local.
3. **Desarrollo de contenido:** Se elaboró un tutorial sobre Git basado en el libro "Pro Git", redactando diferentes capítulos en documentos de Microsoft Word y exportándolos a PDF.
4. **Gestión de versiones:** Se utilizó Git para registrar y subir los cambios al repositorio remoto en cada avance de los capítulos.

## Comandos Utilizados
A lo largo del proyecto se utilizaron los siguientes comandos básicos de Git:
* `git clone [url]`: Para clonar el repositorio inicial a la máquina local.
* `git add .`: Para preparar los archivos de Word y PDF creados en el directorio.
* `git commit -m "mensaje"`: Para confirmar los cambios localmente con mensajes descriptivos.
* `git push`: Para enviar los commits al repositorio remoto en GitHub.

## Cambios Realizados en los Documentos
* Se crearon los documentos iniciales en formato `.docx` con el resumen de los capítulos del libro Pro Git.
* Se exportaron las versiones finales de cada capítulo a formato `.pdf`.
* Se incluyó este archivo `README.md` para documentar el proceso del repositorio.
